## 四、美术风格建议

### 4.1 推荐风格：扁平像素 + 深夜办公室

| 元素 | 建议 |
|------|------|
| **主色调** | 深蓝紫色 (#1a1a2e, #16213e) |
| **强调色** | 霓虹蓝 (#0f4c75)、橙色 (#f39c12) |
| **UI风格** | 扁平化 + 轻微发光效果 |
| **角色** | Q版2头身，职业特征明显 |
| **卡牌** | 圆角矩形，图标+文字，稀有度颜色边框 |

### 4.2 各职业视觉特征

| 职业 | 视觉特征 | 配色 |
|------|----------|------|
| 程序员 | 眼镜、格子衫、咖啡 | 蓝绿色 |
| HR | 正装、文件夹、微笑 | 紫色 |
| 财务 | 眼镜、计算器、严肃 | 深蓝色 |
| 运营 | 休闲装、数据图表 | 橙色 |
| 销售 | 西装、手机、自信 | 红色 |

### 4.3 海克斯稀有度颜色

| 稀有度 | 颜色 | 效果 |
|--------|------|------|
| 普通 | 白色/灰色 | 无发光 |
| 稀有 | 蓝色 | 轻微发光 |
| 史诗 | 紫色 | 明显发光 |
| 传说 | 金色 | 强烈发光+粒子 |
