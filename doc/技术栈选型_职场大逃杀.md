# 《职场大逃杀》技术栈选型文档

| 层级 | 技术 | 版本 | 用途 |

## 二、为什么选择 Godot

### 2.1 Godot 优势

| 优势 | 说明 |
|------|------|
| **轻量** | 下载仅几十MB，秒开，对硬件要求低 |
| **开源** | MIT协议，无版权顾虑，可自由修改引擎 |
| **GDScript** | 类似Python，前端工程师友好，学习成本低 |
| **2D优先** | 卡牌游戏2D表现足够，2D工具链成熟 |
| **内置网络** | 后续多人扩展简单，无需额外框架 |
| **节点系统** | 类似React组件化思维，前端工程师易理解 |
| **导出方便** | 一键导出PC/Mac/Linux/Web/移动端 |

### 2.2 与其他引擎对比

| 特性 | Godot | Unity | Unreal |
|------|-------|-------|--------|
| 安装包大小 | 40MB | 3GB+ | 10GB+ |
| 授权费用 | 免费 | 年收入$10万+收费 | 5%分成 |
| 2D工具 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ |
| 学习曲线 | 平缓 | 中等 | 陡峭 |
| 卡牌游戏生态 | 够用 | 丰富 | 较少 |
| 代码热重载 | ✅ 支持 | ⚠️ 有限 | ❌ 不支持 |

**结论**：对于独立开发的卡牌策略游戏，Godot是最优选择。

## 三、项目架构设计

### 3.1 整体架构

```
┌─────────────────────────────────────────────┐
│              表现层 (UI/动画)                │
│         Godot UI + Tween动画                │
├─────────────────────────────────────────────┤
│              逻辑层 (游戏核心)               │
│    ┌─────────┐    ┌─────────────────┐      │
│    │ 单机模式 │    │ 网络模式接口    │      │
│    │(本地AI) │    │(预留Multiplayer)│      │
│    └─────────┘    └─────────────────┘      │
│              ↑ 统一接口，可切换              │
├─────────────────────────────────────────────┤
│              数据层                          │
│    本地存档 (SQLite) + 配置 (JSON)          │
│    ScriptableObject风格 (Resource)          │
├─────────────────────────────────────────────┤
│              AI层                            │
│    行为树 (自定义实现)                       │
│    决策评估 (Minimax算法)                    │
└─────────────────────────────────────────────┘
```

### 3.2 核心设计原则

1. **核心逻辑与引擎解耦**：纯GDScript类，不依赖Godot节点，方便单元测试
2. **状态管理集中化**：GameManager单例管理全局状态，类似Redux
3. **数据驱动**：卡牌、海克斯、事件等配置化，方便调整平衡
4. **模块化设计**：各系统独立，降低耦合
5. **预留扩展**：网络接口预留，单机→多人改动最小

## 五、核心系统实现

### 5.1 全局状态管理（GameManager）

```gdscript
# autoload/GameManager.gd
extends Node

# 信号
signal turn_changed(turn_number: int)
signal phase_changed(phase: String)
signal player_updated(player_id: String)
signal game_over(winner: Player)

# 游戏状态
var current_turn: int = 1
var current_phase: String = "action"  # action/work/settlement/shop/quarter_end
var current_month: int = 1  # 1-3
var current_quarter: int = 1
var game_speed: float = 1.0

# 游戏实体
var players: Array[Player] = []
var departments: Array[Department] = []
var player_character: Player  # 玩家控制的角色

# 配置
var config: GameConfig

func _ready():
    config = load_config()
    connect_signals()

func start_new_game(difficulty: String, profession: Profession):
    reset_game()
    init_departments()
    init_players(difficulty, profession)
    start_turn()

func init_departments():
    departments = [
        Department.new("技术部", Profession.PROGRAMMER),
        Department.new("人事部", Profession.HR),
        Department.new("财务部", Profession.FINANCE),
        Department.new("运营部", Profession.OPERATION),
        Department.new("销售部", Profession.SALES),
    ]

func init_players(difficulty: String, player_profession: Profession):
    players.clear()
    
    # 创建AI玩家（19个）
    for i in range(19):
        var ai = Player.new()
        ai.is_ai = true
        ai.ai_type = AIType.random_type(difficulty)
        ai.profession = Profession.random()
        ai.department = get_department_by_profession(ai.profession)
        ai.department.add_member(ai)
        players.append(ai)
