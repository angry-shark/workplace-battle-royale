# 《职场大逃杀：最后打工人》游戏策划案

## 一、游戏概述

### 1.1 核心概念
《职场大逃杀》是一款以现代职场为背景的Roguelike策略生存游戏。玩家扮演一名普通打工人，在"HC（Headcount，编制）紧缩"的大环境下，与其他同事展开生存竞争。游戏融合了自走棋的缩圈机制、卡牌策略的战斗系统、以及Rogue元素的海克斯科技系统。

### 1.2 核心体验
- **紧张感**：每季度缩圈的生存压力
- **策略深度**：海克斯搭配 + 职场策略卡组合
- **随机性**：每局不同的海克斯和事件
- **黑色幽默**：职场梗与现实讽刺

### 1.3 目标平台
PC / Steam / 移动端（后续）

## 二、核心机制

### 2.1 双资源系统

#### 部门HC分配机制

**部门划分**：
- 技术部（程序员）
- 人事行政部（HR行政）
- 财务部（财务）
- 运营部（运营）
- 销售部（销售）

**HC分配规则**：
- 每季度总HC减少20%（缩圈）
- 减少的HC名额按**部门绩效**分配到五个部门
- **部门绩效** = 该部门所有成员的人均绩效

**分配示例**：
```
假设本季度总HC从100减少到80（需淘汰20人）

部门绩效排名：
1. 销售部：人均绩效120 → 分配0个淘汰名额
2. 运营部：人均绩效110 → 分配2个淘汰名额
3. 技术部：人均绩效100 → 分配5个淘汰名额
4. 财务部：人均绩效90 → 分配6个淘汰名额
5. 人事部：人均绩效80 → 分配7个淘汰名额

各部门内部按个人绩效排名，末尾淘汰
```

**策略意义**：
- 个人绩效影响部门排名，部门排名影响个人生存
- 可能出现"躺平部门集体暴毙"或"神仙部门全员存活"
- 跨部门陷害可以削弱其他部门，间接保护自己
- 部门内部既是队友也是竞争对手

#### 健康度（HP）
- **初始值**：100点
- **可见性**：**对外不可见**，仅自己可见（隐藏血量机制）
- **消耗途径**：
  - **基础消耗**：每月固定-5（日常通勤、工作压力）
  - 加班（额外-10）
  - 被陷害（根据策略卡效果）
  - 饥饿（工资不足以购买食物时-10/月）
  - 项目失败（-15）
- **恢复途径**：
  - 购买食物（工资兑换）
  - 特定海克斯效果
  - 休假卡（罕见）
- **信息博弈**：需要通过观察对方行为（如频繁买食物、使用防御卡）推测其HP状态

#### 职场绩效（KPI）
- **个人绩效计算**：每月根据工作产出 + 海克斯加成 + 策略卡效果综合计算
- **可见性**：**仅自己可见**，季度结算时公示全公司排名
- **部门绩效计算**：该部门所有成员的人均绩效（每季度末计算）
- **淘汰规则**：
  - 每季度末先计算各部门绩效排名
  - 按排名分配各部门淘汰名额（排名越低，名额越多）
  - 各部门内部按个人绩效排名，末尾淘汰
  - 总淘汰人数 = 缩圈减少的HC数量
- **缩圈**：每季度HC上限减少20%
- **季度重置**：每季度开始时全员绩效完全清零，初始绩效无差异
- **信息博弈**：平时无法得知他人绩效，需要通过海克斯（如【八卦雷达】）或策略卡（如【考勤记录】）获取情报

### 2.2 工资系统

#### 工资特性
- **可见性**：**对外不可见**，仅自己可见（隐私机制）
- **继承性**：工资**不随季度重置**，永久累积
- **初始工资**：由**职级**决定（见职级系统）
- **工资来源**：
  - 基础工资（职级决定）
  - 绩效奖金（每月根据绩效浮动）
  - 海克斯加成（如【副业收入】）
  - 策略卡效果（如【报销技巧】）
- **工资用途**：
  - 购买食物恢复HP
  - 购买策略卡
  - 使用特殊技能（如【挖角专家】）
- **信息博弈**：无法直接看到他人工资，但可以通过观察其消费能力（买多少食物、卡）推测

### 2.3 职级系统（P1-P12）

#### 职级结构（金字塔形）

| **基层** | P1-P3 | 50% | 低 | 容易 | 3张 |

| **专家** | P7-P9 | 15% | 高 | 困难 | 5张 |

#### 晋升机制
- **晋升条件**：
  1. 部门内绩效排名**前3**
  2. 在当前职级待满**所需季度数**
  3. 通过晋升评审（**50%随机通过率**）
- **玩家选择权**：
  - 晋升机会出现时，玩家可以**选择接受或拒绝**
  - **拒绝晋升**的好处：保持在当前职级，绩效更容易，继续积累工资
  - **接受晋升**的好处：更高工资、更多策略卡、更高社会地位
- **晋升风险**：
  - 高职级绩效更难提升（系数降低）
  - 更容易成为陷害目标（树大招风）
  - 部门HC减少时，高职级更容易被优化（成本高）

#### 职级与策略卡
- 每个职级有**专属的策略卡池**
- 职级越高，解锁的**策略卡越强**
- 低职级只能使用基础卡，高职级可以使用高级卡（如部门级策略卡）

### 2.4 时间系统

| 周期 | 事件 |
|------|------|
| **月度** | 扣除基础健康度 → 行动阶段（使用职场策略卡）→ 工作产出 → 工资结算 → 商店购买 |
| **季度** | **全员绩效重置** → HC盘点（缩圈+淘汰）→ 晋升评审 → 抽取海克斯科技 |
| **年度** | 特殊事件（裁员潮/公司并购等）|

#### 月度健康度扣除（基础消耗）
- 每月固定扣除 **5点HP**（代表日常通勤、工作压力的基础消耗）
- 可通过海克斯减免（如【养生达人】每月只扣3HP）

#### 季度绩效重置机制
- **重置时机**：每季度第1个月开始前
- **重置规则**：
  - **绩效完全清零**，所有人回到同一起跑线（初始绩效无差异）
  - **海克斯清空**：本季度获得的海克斯全部移除（除极少数"永久型"海克斯）
  - **工资保留**：工资永久累积，不随季度重置
  - **职级保留**：职级永久保留，不随季度重置
  - 每季度重新抽取海克斯，全新Build
- **永久型海克斯**（极少数，金色传说）：
  - 【躺平仙人】：HP不会低于1（被动效果）
  - 【财富自由】：工资永久+50%（经济效果）
  - 其他海克斯均季度清零
- **设计目的**：
  - 每季度绩效独立，防止滚雪球
  - 工资和职级长期累积，体现成长感
  - 海克斯Build每季度重新选择，增加策略深度
  - 落后者每季度都有翻盘机会，但长期积累仍有优势

### 3.3 海克斯类型说明

| 类型 | 说明 | 数量 |
|------|------|------|
| **季度型** | 每季度重置时清空，需重新抽取 | 绝大多数 |
| **永久型** | 获得后永久保留，跨季度生效 | 极少数（仅传说级） |

**永久型海克斯设计原则：**
- 仅影响HP或经济，不影响绩效平衡
- 获得难度极高（金色传说，1%概率）
- 效果不会破坏每季度的公平竞争

### 3.4 海克斯联动机制

**Combo示例（需在一季度内完成）：**
- 【996福报】+ 【养生达人】+ 【抗压王者】= "卷王生存流"
- 【双面间谍】+ 【职场幽灵】+ 【甩锅大师】= "老六阴人流"
- 【PPT之神】+ 【向上管理】+ 【嫡系光环】= "嫡系卷王流"

### 4.2 卡牌使用规则
- 每月可使用 **2张** 策略卡（可通过海克斯增加，职级越高上限越高）
- 陷害卡有 **暴露风险**，暴露后成为"公敌"
- 联盟卡需要 **双方同意**（AI可能拒绝）
- 特殊卡 **不占用手牌上限**
- **职级限制**：部分高级策略卡（如部门级）需要P7以上职级才能使用

## 六、AI同事系统

### 6.1 AI类型

| 类型 | 特点 | 行为模式 |
|------|------|----------|
| 卷王型 | 高绩效，低HP | 优先选绩效海克斯，频繁加班，积极晋升 |
| 养生型 | 高HP，低绩效 | 优先选生存海克斯，拒绝加班，拒绝晋升 |
| 老六型 | 中等属性，爱陷害 | 随机选择目标陷害，收集信息，精准打击 |
| 社交型 | 爱结盟，重关系 | 主动发起联盟，背叛率低，信息共享 |
| 随机型 | 完全随机 | 新手友好，不可预测 |
| **晋升型** | 追求高职级 | 每季度必争前3，接受所有晋升 |
| **潜伏型** | 隐藏实力 | 故意保持中等绩效，隐藏HP和工资，关键时刻爆发 |

### 6.2 AI难度
- **简单**：AI不会针对玩家，陷害率低，信息隐藏意识弱
- **普通**：正常竞争，偶尔针对，会基础的信息收集
- **困难**：AI会针对高绩效玩家，联盟更稳固，会推测玩家HP和工资
- **地狱**：AI会记仇，长期联盟，精准打击低HP目标，玩家1vN

### 6.3 AI信息处理
- **简单AI**：不隐藏信息，HP和工资外露
- **普通AI**：基础隐藏，偶尔暴露
- **困难AI**：主动隐藏，通过行为误导玩家
- **地狱AI**：完美隐藏，反向推理玩家状态，制造假信息

## 七、游戏流程

### 7.1 单局流程

```
开始游戏
    ↓
选择难度（简单/普通/困难/地狱）
    ↓
初始海克斯抽取（3选1）
    ↓
【第1月】扣除基础HP → 工作 → 行动 → 结算 → 商店
    ↓
【第2月】扣除基础HP → 工作 → 行动 → 结算 → 商店
    ↓
【第3月】扣除基础HP → 工作 → 行动 → 结算 → 商店
    ↓
【第1季度】绩效清零 + 海克斯清空 → HC盘点 → 淘汰 → 重新抽取海克斯
    ↓
...重复直到...
    ↓
胜利条件：成为最后1人 / 触发特殊胜利
失败条件：HP归零 或 绩效垫底被淘汰
```

### 7.2 胜利条件

## 十五、信息隐藏与博弈系统

### 15.1 隐藏信息汇总

| 信息类型 | 可见性 | 获取方式 |
|----------|--------|----------|
| **HP（健康度）** | 仅自己可见 | 海克斯【八卦雷达】【部门间谍】、策略卡【考勤记录】、观察行为推测 |
| **绩效** | 仅自己可见，季度公示 | 同上 |
| **工资** | 仅自己可见 | 海克斯【财务总监】、策略卡【考勤记录】、观察消费能力推测 |
| **职级** | 公开可见 | 直接查看 |
| **海克斯** | 部分公开（效果可见） | 观察其行为效果推测 |
| **手牌** | 仅自己可见 | 海克斯【档案管理员】、策略卡【考勤记录】 |

### 15.2 信息获取手段

#### 海克斯类
- 【八卦雷达】：每月随机得知1人HP或绩效
- 【部门间谍】：每月查看其他部门1人完整状态
- 【财务总监】：查看所有人工资
- 【档案管理员】（永久）：持续监控1人

#### 策略卡类
- 【考勤记录】（HR专属）：查看目标完整状态
- 【用户洞察】（运营专属）：查看海克斯选项

#### 观察推理
- **HP推测**：频繁买食物 → HP低；使用防御卡 → 可能被针对
- **绩效推测**：工作卡选择 → 绩效策略；海克斯选择 → 打法倾向
- **工资推测**：购买频率和档次 → 工资水平

### 15.3 信息战策略

| 策略 | 说明 |
|------|------|
| **隐藏实力** | 故意买便宜食物，隐藏真实HP；选择中庸工作卡，隐藏绩效策略 |
| **虚张声势** | 买贵食物假装HP健康；高调使用工作卡假装绩效高 |
| **精准打击** | 通过信息获取找到低HP目标，一击必杀 |
| **情报联盟** | 与HR或信息型玩家结盟，共享情报 |

## 十六、游戏平衡设计

### 16.1 反滚雪球机制

| 机制 | 说明 |
|------|------|
| 季度绩效重置 | 每季度清零，所有人同一起跑线 |
| 职级绩效惩罚 | 高职级绩效更难提升，防止高工资+高绩效双重优势 |
| 树大招风 | 高职级更容易成为陷害目标 |
| 晋升随机性 | 50%通过率，防止稳定晋升 |
| 部门竞争 | 个人强但部门弱仍可能被淘汰 |

### 16.2 多种获胜路径

| 路径 | 核心策略 |
|------|----------|
| **卷王流** | 高职级 + 高绩效，正面碾压 |
| **潜伏流** | 低职级隐藏，关键时刻爆发 |
| **经济流** | 累积工资，购买优势 |
| **信息流** | 掌握情报，精准打击 |
| **联盟流** | 抱团取暖，集体生存 |
| **老六流** | 陷害专家，借刀杀人 |
